# M4: Focus Navigation

## Goal

- 大規模なマップでも、不要な枝を畳み、対象のサブツリーへ集中できるようにする
- キーボード中心の操作感を維持し、現在位置と全体への戻り道を明確にする

## Features

- 枝の折りたたみ: `za` / `zc` / `zo`
- 表示範囲の全折りたたみ・全展開: `zM` / `zR`
- 選択枝へのフォーカス: `F`
- `Esc`、`h`、パンくずによるフォーカス階層の移動
- Search選択時の祖先自動展開
- 可視ノードだけを対象にしたJumpヒント
- 折りたたみ状態の永続化

## Compatibility

- 旧workspaceでは折りたたみ状態を空として読み込む
- フォーカス状態はセッション限定とする
- Rust保存モデルにノードメモを追加し、既存メモを欠落なく保存する
