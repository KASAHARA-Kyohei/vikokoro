# M6: Manual Connector Anchors

## 概要

親子線ごとに、親側・子側の接続辺を手動指定できるようにする。
自動判定は維持し、必要な線だけ `top/right/bottom/left` を上書きする。

## 実装範囲

- `DocumentState.edgeAnchors` を追加
  - キーは `parentId->childId`
  - 値は `{ from, to }`
  - `null` は自動判定
- Rust保存モデルへ `edgeAnchors` を追加し、旧JSONは空オブジェクトで読み込む
- 手動指定があれば接続線端点に反映し、未指定側は横優先の自動判定を使う
- 線クリックで選択し、選択線に関係する2ノードへ上下左右ハンドルを表示
- `Auto` ボタンとコマンドパレットで選択線を自動判定へ戻す
- アンカー変更とAutoリセットはUndo/Redo対象
- ノード削除、親変更、AI適用、旧JSON読み込み時に無効なアンカーを除去

## 対象外

- 任意座標アンカー
- 折れ点編集
- 相互リンクや非親子リンク
