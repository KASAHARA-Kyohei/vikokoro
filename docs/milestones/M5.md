# M5: Free Layout Editing

## Goal

- 親子階層とキーボード操作を維持しながら、考えのまとまりを空間的に自由配置できるようにする
- 自由配置と右向き自動整列を必要に応じて切り替えられるようにする

## Features

- ノード単体、枝全体、複数選択のドラッグ移動
- `Shift+Click` と矩形選択
- 空白ダブルクリックによる位置指定の子ノード作成
- 整列ガイドと軽い吸着
- `Alt+h/j/k/l` による位置の微調整
- `=` / `+` による枝 / 全体の自動整列
- 任意方向の親子線と自動拡張キャンバス
- 座標を含むUndo/Redo、Tauri保存、AI生成・改善連携

## Compatibility

- 旧workspaceでは不足座標を右向きツリー配置で補完する
- 折りたたみ・フォーカス時も保存座標は変更しない
- 完全自由グラフ、補助リンク、未接続ノード、無限キャンバスは対象外とする
